- 新增“稍后再看”（需登录）：滚动到底自动加载，可按添加时间排序，按观看进度、加入时间和时长筛选，并在工具栏右侧搜索；番剧、课程和已失效的条目会标出原因，不能播放。
- 新增“收藏夹”（需登录）：侧栏逐个列出自己创建的收藏夹，私密收藏夹带锁图标；夹内视频按页码翻页，可按最近收藏、最多播放、最近投稿排序，并在当前收藏夹里搜索。
- 侧栏改为分组：顶部是搜索、首页和热门，“资料库”里是稍后再看与观看历史，之后是可折叠的“收藏夹”。
- 弹幕重写：拖动进度条时弹幕跟着画面走，跳转后立即显示该时刻屏上应有的全部弹幕。
- 暂停、继续播放和跳转后开始播放时，弹幕不再往回缩或突然跳动。
- 调整窗口大小、进入或退出全屏时，屏上的弹幕不再重新排列，字号保持不变；窗口变大时露出更多弹幕。
- 修改弹幕设置、在不同屏幕之间移动窗口时，屏上的弹幕立即换到新的位置，不再停住后整屏替换。
- 修复很长的弹幕在不同屏幕之间移动窗口后不再显示的问题。
- 跳转、拖动进度条（包括暂停时）需要等待画面时，显示加载转圈；旁白读作“正在加载”。
- 暂停画面不再提供实况文本（选取画面中的文字），暂停响应更快。
- 暂停时会同时结束长按方向键的临时倍速。
- 大多数视频的原声和 AI 配音改用最高档音质。
- AI 配音加载失败时，视频继续用原声播放。
- 某一档清晰度加载出错时，可以换用其他清晰度继续播放。
- 加载中的占位卡片铺满整个窗口；评论区加载改为转圈。
- 首页、热门、搜索和观看历史刷新后，新卡片立即显示，并且能继续滚动加载。
- 热门、搜索和观看历史最多显示 1000 条，长时间使用时内存占用更稳定。
- 账号在其他地方退出后，BiliKit 会回到未登录状态并提示登录，不再一直显示网络错误。
- 被 B 站限制访问时，请求次数大幅减少。
