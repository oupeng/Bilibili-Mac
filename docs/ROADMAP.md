# BiliKit 路线图

## 产品目标

为 Mac 设计的原生、克制、非官方 B 站浏览与播放客户端。不复制网页全部功能，而是让发现内容、进入
视频、连续观看和返回来源发生在一个稳定的 Mac 窗口里。观看有两条路线：

```text
发现：首页推荐／热门／搜索／稍后再看／观看历史／收藏夹 → 同窗口视频页
      → 播放 + 字幕 + 弹幕 + 分 P + 只读评论 → 相关推荐连续观看
深入：视频页的 UP 主 → 侧栏上的 UP 主空间 → 按投稿连续观看同一创作者，视频不中断
两条路线共同：登录后自动同步服务端观看进度 → 返回并恢复来源上下文
```

两条路线都已成立。UP 主空间第一版只有投稿列表；合集由视频页侧栏的选集承载。

## 当前能力

每项一行；行为细节以代码与测试为准，模块与决定见 [`ARCHITECTURE.md`](ARCHITECTURE.md)。

- 浏览：首页个性推荐（过滤商业推广与非视频条目）、热门、搜索（起始页的本机搜索历史与 B 站热搜、系统联想
  菜单，匿名、无开关）；各入口保留自己的工作集与滚动位置。
- 资料库（登录后）：观看历史、稍后再看（排序、筛选与关键词）、收藏夹（侧栏逐个列出，夹内按页翻页、
  排序与搜索）；打不开的条目显示为标明原因的不可用卡片。不做“播放全部”。
- 播放：单一 player host，自动画质、seek、倍速、系统字幕与音轨菜单、弹幕（含大会员彩色弹幕；B 站标记的高赞
  弹幕开头带与文字同色的赞图标，不显示赞数、无开关；合并重复弹幕默认开，同一位置、内容相同、在组首仍可见期间
  到达的弹幕（滚动弹幕按 640pt 宽播放区里的可见时长算，顶部与底部 4 秒）只显示组首一条，正文右侧的深色胶囊白字计数从第二条到达起出现、每到一条直接加一，
  顶部与底部弹幕按正文居中、胶囊挂在右边；不跨分段、不跨组累计）、Now Playing、全屏与 PiP、键盘
  快捷键；游客可选 720P／1080P，登录用户按账号权限取流。
- 视频页：主区固定，侧栏承载简介、分 P、只读评论（排序、分页、楼中楼、图片、受控外链）；简介与评论里的
  站内链接、@ 与时间戳在应用内打开或跳转；相关推荐横排。楼中楼按页码直接跳页，翻页、收起后停在这一楼；回复别人的
  回复可「查看对话」，面板原地换成按楼层排列的那串对话（不缩进，不做树状），「返回全部回复」回到原页。
- UP 主空间（登录后）：作为侧栏上下文层打开，按投稿连续观看，视频不中断。
- 稍后再看的加入与移除（登录后，用户发起）：可播放卡片的右键菜单与读屏操作里「添加到稍后再看」，稍后再看页「从
  稍后再看移除」（失效视频也可以）与 ⌘⌫；不确认、不撤销，失败放回原位，结果在窗口底部的胶囊里说明；写入不重试、
  不排队、不保存。
- 收藏（登录后，用户发起）：可播放卡片的右键菜单与读屏操作里「收藏到…」，面板列出自己的收藏夹并勾选当前归属，
  确认后一次提交差异（第一版不新建收藏夹）；收藏夹页「从此收藏夹移除」（失效视频也可以）与 ⌘⌫，失败放回原位；
  不确认、不撤销，结果在窗口底部的胶囊里说明，写入不重试、不排队、不保存。
- 点赞、投币、三连（登录后，用户发起）：播放页工具栏一组点赞、投币、收藏按钮（图标加计数，做过的实心）；点赞点一下完成、
  再点撤回（Q），投币打开面板选 1／2 枚（转载 1 枚，可同时点赞，W），收藏打开「收藏到…」（E），长按 Q 1 秒三连；全屏下
  W／E 只提示先退出全屏；未登录时按钮禁用、计数照常。结果在窗口底部的胶囊里说明，写入不重试、不排队、不保存。部分
  视频会被 B 站以账号异常（-403）拒绝，胶囊说明可在网页上完成并给出「在浏览器中打开」。
- 不感兴趣（登录后，用户发起）：首页推荐卡片的右键菜单与读屏操作里「不感兴趣 ▸」，原因照网页首页只有「内容不感兴趣」与
  「不想看此 UP 主」；卡片留在原位、变暗并标「将减少此类推荐」，不能进入播放，菜单里可「撤销不感兴趣」；刷新推荐后只有仍在
  推荐里的卡片保持标记，其余的不能再撤销。不确认，失败放回，结果在窗口底部的胶囊里说明，写入不重试、不排队、不保存。
- 视频卡片菜单：各来源的卡片右键菜单与读屏操作同源，提供拷贝链接与在浏览器中打开。
- 账户：二维码登录；登录播放自动同步观看进度（无开关，失败不影响播放）。
- 响度均一化（macOS 27 起，默认关闭）；实验能力：显式播放线路选择与测速。
- 分发：Developer ID 签名公证 DMG + Sparkle 更新；1.0.1 起仅 Apple Silicon。

## 当前阶段：1.x 观看体验

新的工作排期时，每项开始前先确认待定问题，并在本文写明结论。发布仍按
[`release/README.md`](release/README.md) 执行。不借机增加新 target；账户写入只做本文“当前能力”里列出的操作，新的写操作各自
排期并先写入本文，共用已有的写授权器与写入协调，不另建通用写入通道。

已排期的搜索历史与 B 站热搜、搜索联想、架构重构（新增 `BiliVideoCollectionUI` 与 `BiliVideoDetailFeature` 两个
target）、稍后再看、收藏夹、加载状态、视频卡片菜单、稍后再看的加入与移除、收藏到收藏夹与从收藏夹移除、点赞投币三连、首页
推荐的不感兴趣、楼中楼页码与查看对话、高赞弹幕、重复弹幕合并已完成（结论见“当前能力”）。

已排期，按表中顺序进行；完成一项后移入“当前能力”，并删去这一行：

| 排期 | 用户结果 | 开始前先确认 |
| --- | --- | --- |
| 互动弹幕 | 评分、投票、关联视频等互动弹幕在对应时间显示为窗口 | 窗口位置与显隐（与“不因 API 存在就加浮层”对照）、评分与投票只看结果还是可提交 |
| 播放器动作菜单 | 窗口与全屏下都能从原生控制条的动作菜单（AVKit `actionPopUpButtonMenu`，随原生控件显隐）操作当前视频：添加到稍后再看；拷贝链接（带当前时间）、拷贝 BV 号、在浏览器中打开；“播放结束后”单选不循环、单集循环、自动连播、列表循环，选择存入偏好 | 列表范围（只含分 P 与合集，不含相关推荐，见界面原则）；单 P 视频上四项照常可选（这是全局偏好，不是单个视频的设置），自动连播播完即停、列表循环等同单集循环；单集循环回到开头时弹幕补位、“从头播放”提示与进度上报的表现；下一集不可播时停下并说明；全屏浮动控制条里动作菜单是否出现；拷贝链接在开头几秒是否省略时间、在浏览器中打开是否带时间并暂停应用内播放 |
| 发送弹幕（写入） | 登录后在当前播放位置发一条弹幕，发出后立即在画面上看到 | 自己发的弹幕不参与重复合并（已定）；输入入口（不复制网页播放器控制条）、颜色／位置／字号选项、被拒绝与频率限制的呈现、实测用哪个稿件并在测后删除。入口若做成播放器悬浮按钮：AVKit 没有公开的控件显隐接口；读取它的私有视图层级（控件容器的透明度）在窗口与全屏下都能与原生控件同步显隐，但这是全屏切换之外的第二个私有依赖，采用前须改 ARCHITECTURE，并在层级找不到时退回按鼠标计时显隐；原生控件窗口下是磨砂玻璃、全屏下是液态玻璃，按钮材质要随之切换 |
| 评论回复（写入） | 登录后在评论区回复一条评论或楼中楼 | 是否同时做一级评论、删除自己的评论与评论点赞；被风控或仅自己可见的呈现；实测用哪个稿件并在测后删除 |
| 动态 | 在侧栏看关注的人的动态，视频动态直接进入播放 | 按“范围变更”说明真实空白与失败形态；文字与图文 post 的排版设计；第一版包含的动态类型；详情与评论；不做发动态与动态写入 |

## 非目标

- 下载、转码、媒体导出和离线媒体库；直播；多账号。唯一例外：评论图片预览里由用户逐张保存原图。
- 区域解锁、DRM 绕过或权限规避。
- 关注、点踩、发动态等写操作；评论与弹幕的写入只做“当前阶段”已排期的范围；“当前能力”与排期之外的账户写入，
  包括批量管理、清空稍后再看或清除已看完、手动排序、重命名或删除收藏夹、在收藏夹之间移动或复制。
- 自研更新器、自动降级、Cloudflare 下载或 B 站代理。
- 为减少加载而引入通用 Cache、数据库或 Shared Store。

## 界面原则

- 使用系统窗口、侧栏、toolbar、菜单、focus 与辅助功能行为，不复制网页导航或播放器控制条。
- 首页推荐与热门语义不同，不互相冒充；每个入口的状态、分页与滚动独立，不共享可互相污染的页面状态。
- 状态诚实：加载、失败、登录限制准确呈现；刷新失败不清空仍可用结果；不伪造内容，不用登录诱导代替错误。
- 视频页是同窗口层级导航，返回恢复来源；切换分 P 不增加层级。播放器是主区稳定锚点，resize、全屏、
  PiP、返回与媒体替换都不创建第二个 player host。
- 侧栏在播放态由单一滚动 owner 组织简介、分 P 与评论；评论加载、图片与外链不控制播放器。
- 相关推荐不自动播放、不无限循环。外链只在用户点击后经严格解析再打开。
- BiliKit 特有 action 必须有明确用户结果，不因 API 存在就加浮层。
- VoiceOver、Full Keyboard Access、动态文字和高对比度需真人验证；截图和 AX tree 不构成验收。

## 范围变更

新页面、写操作、持久化或自定义播放器 UI 需先说明解决的真实空白、失败时页面是否仍成立、owner 与
清理点，再更新本文。不以占位 target、预留 UI 或未调用抽象提前进入工程。
