# BiliKit 路线图

## 产品目标

为 Mac 设计的原生、克制、非官方 B 站浏览与播放客户端。不复制网页全部功能，而是让发现内容、进入
视频、连续观看和返回来源发生在一个稳定的 Mac 窗口里。观看有两条路线：

```text
发现：首页推荐／热门／搜索／稍后再看／观看历史／收藏夹 → 同窗口视频页
      → 播放 + 字幕 + 弹幕 + 分 P + 只读评论 → 相关推荐连续观看
深入：视频页的 UP 主 → 侧栏上的 UP 主空间 → 按投稿连续观看同一创作者，视频不中断
两条路线共同：登录后自动同步服务端观看进度 → 返回并恢复来源上下文
```

两条路线都已成立。UP 主空间第一版只有投稿列表；合集由视频页侧栏的选集承载。

## 当前能力

- 首页个性推荐（过滤商业推广与非视频条目）、热门、搜索、二维码登录、观看历史；各入口保留自己的
  工作集与滚动位置。
- 观看历史卡片在日期前用系统图标区分观看设备（手机、平板、网页、电视），设备未知时不显示。
- 侧栏分组：顶部不带标题的搜索、首页、热门，「资料库」（稍后再看、观看历史），以及登录后可折叠的「收藏夹」。
- 稍后再看（只读，登录后）：`/x/v2/history/toview/web` 经 WBI 签名只按账户读取，未登录或本地无凭据时直接失败；
  每页 20 条、最新加入在前，滚到底自动加载下一页，本页有条目且已请求条数少于接口总数才有下一页，不另设条数上限
  （内存仍最多保留 1000 条）；进入来源时加载，工具栏刷新原地进行。番剧／影视、课程与已失效条目显示为变暗的不可用
  卡片并在角标写原因，点击、回车与读屏都不进入播放；充电专属照常进入播放页处理。排序（最近／最早添加）、筛选
  （观看进度、加入时间含自定义日期、时长四档，弹窗应用后生效）与工具栏尾部搜索框的关键词（服务端过滤）都是请求
  条件，条件变化重新加载并回顶；副标题显示当前条件下的总数。条件只在窗口内存里。不做网页端的“清除已看完”“批量
  管理”与“播放全部”，也不提供加入、移出等写操作。
- 收藏夹（只读，登录后）：侧栏「收藏夹」组逐个列出自己创建的收藏夹（`/x/v3/fav/folder/created/list-all`，一次取全、
  不签 WBI，mid 取自窗口账户；私密夹名称右边加锁），点一行直接在右侧看夹内视频（`/x/v3/fav/resource/list`，不签 WBI，
  `platform=web`，每页 40 条），按页码整体替换，底部页码条翻页与跳页；排序（最近收藏／最多播放／最近投稿）与工具栏尾部
  搜索框（只搜当前收藏夹）都整体替换并回顶。普通视频（含仅自己可见）可播放；合集、音频、番剧／影视、未知类型与已失效
  条目显示为不可用卡片并写原因。Cookie 失效时接口不报错而退化为访客视角，没有默认收藏夹即按凭据可疑复核一次；默认
  收藏夹公开时这一判定发现不了失效（只是少了私密夹），要靠其他账户读取报错触发复核。选择、
  排序与关键词只在窗口内存里，不提供收藏、取消收藏、移动等写操作。
- 单一 player host：自动画质、seek、倍速、系统字幕、弹幕（含大会员彩色弹幕）、语义音轨、Now Playing、全屏与 PiP；
  键盘快捷键（空格、←／→、长按临时倍速、音量、D 弹幕、C 字幕、F 全屏）。
- 视频页主区固定：视频与相关推荐不随页面滚动；标题与播放、弹幕、发布时间在工具栏，弹幕开关与设置在
  工具栏弹出面板。
- 游客可选 720P／1080P；登录用户按账号权限取流。
- 只读评论（排序、分页、楼中楼、图片、受控外链）与相关推荐横向 shelf；失败不中断播放。
- 加载状态：首页、热门、搜索、观看历史、稍后再看、收藏夹的视频网格与播放页相关推荐横排，加载中的骨架
  铺满可见区域、随窗口缩放增减；评论区的首次加载、重新加载与追加都用转圈，与 UP 主空间一致。
- 简介与评论正文里的视频链接、短链、@ 与时间戳在应用内播放、打开空间或跳转，其余外链交给浏览器。
- UP 主空间（登录后）：从播放侧栏的 UP 主行、评论作者或评论里的 @ 进入，作为一层压在侧栏上，视频不中断；
  最新发布／最多播放／最多收藏三种排序，底部页码条翻页与跳页；在空间里换视频保留空间，从其他入口换视频时关闭。
- 搜索起始页：未提交搜索时显示本机搜索历史（最多 20 条，搜索页清除，登出不清理）与 B 站热搜前 10 条
  （始终匿名读取）；点选任一词即搜索，热搜失败只影响热搜区。
- 搜索联想：编辑工具栏搜索框时弹出系统联想菜单，先列匹配的本机历史，再列 B 站联想（匿名，无开关）；
  选中即搜索。
- 登录播放通过唯一认证写能力同步观看进度，无开关；游客与上报失败不影响播放。
- 响度均一化（macOS 27 起，默认关闭）：把较响的视频压到统一响度，安静的视频保持原样。
- 实验能力：显式播放线路选择与测速。
- Developer ID 签名公证 DMG + Sparkle 更新；1.0.0 为最后一个 Universal 版本，1.0.1 起仅 Apple Silicon。

## 非目标

- 下载、转码、媒体导出和离线媒体库；直播；多账号。唯一例外：评论图片预览里由用户逐张保存原图。
- 区域解锁、DRM 绕过或权限规避。
- 评论、关注、收藏、稍后再看等写操作；观看进度以外的任何账户写入。
- 自研更新器、自动降级、Cloudflare 下载或 B 站代理。
- 为减少加载而引入通用 Cache、数据库或 Shared Store。

## 界面原则

- 使用系统窗口、侧栏、toolbar、菜单、focus 与辅助功能行为，不复制网页导航或播放器控制条。
- 首页推荐与热门语义不同，不互相冒充；每个入口的状态、分页与滚动独立，不共享可互相污染的页面状态。
- 状态诚实：加载、失败、登录限制准确呈现；刷新失败不清空仍可用结果；不伪造内容，不用登录诱导代替错误。
- 视频页是同窗口层级导航，返回恢复来源；切换分 P 不增加层级。播放器是主区稳定锚点，resize、全屏、
  PiP、返回与媒体替换都不创建第二个 player host。
- 侧栏在播放态由单一滚动 owner 组织简介、分 P 与评论；评论加载、图片与外链不控制播放器。
- 相关推荐不自动播放、不无限循环。外链只在用户点击后经严格解析再打开。
- BiliKit 特有 action 必须有明确用户结果，不因 API 存在就加浮层。
- VoiceOver、Full Keyboard Access、动态文字和高对比度需真人验证；截图和 AX tree 不构成验收。

## 范围变更

新页面、写操作、持久化或自定义播放器 UI 需先说明解决的真实空白、失败时页面是否仍成立、owner 与
清理点，再更新本文。不以占位 target、预留 UI 或未调用抽象提前进入工程。
